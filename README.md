Select files in Explorer or a range in Excel and press **Alt + Space**. Search for an action, review its options and preview, then run it. Processing takes place locally on your PC.

```text
Select images and PDFs in Explorer
Alt + Space  →  Search "combine"  →  Combine into one PDF
Review the preview  →  Run  →  A new PDF; source files unchanged
```

## Features

- **Actions for your selection.** Find image and PDF tools for selected files, export actions for Excel ranges, and combination actions for supported mixed selections.
- **Keyboard navigation.** Search by action name, format or purpose, and navigate results with the keyboard.
- **Local processing.** Work with installed tools offline, without an account, cloud processing or telemetry.
- **Preview and safe outputs.** Review options and planned changes before running file actions. Transformations create new files by default; source files are never overwritten silently.
- **Optional tool packs.** Choose packs during setup and manage them in Settings. Packs can be updated separately from the app, and signatures are verified before execution.
- **Windows integration.** Use File Explorer and desktop Excel selections, Windows OCR, light and dark themes, and an English or German interface.

## Get started

1. **Download** the installer or the portable ZIP from [Releases](https://github.com/fgrzesiak/powertrove/releases) or the [download page](https://powertrove.net/en/download).
2. **Install your tools.** In Setup, choose the packs you need; File, PDF and Image Tools are preselected. Setup downloads and verifies the selected packs. With the portable ZIP, install packs in Settings.
3. **Launch PowerTrove**, select files in Explorer or a range in Excel, and press **Alt + Space**.

The first pack download requires an internet connection. Once installed, tools work offline. You can also transfer a signed `.cbpack` file from another PC and install it in Settings.

| Key | What it does |
| --- | --- |
| <kbd>Alt</kbd> + <kbd>Space</kbd> | Open PowerTrove for the current selection (configurable in Settings) |
| <kbd>↑</kbd> <kbd>↓</kbd> | Pick an action |
| <kbd>Enter</kbd> | Open the selected action; review its options and preview before running |
| <kbd>Esc</kbd> | Close the palette or return from the current dialog |

By default, PowerTrove checks for new versions at startup and lets you install updates from within the app. You can disable the startup check in Settings, where you also manage tool pack updates.

> [!NOTE]
> PowerTrove is a **public alpha** for Windows 11 x64. The installer is not code-signed yet, so Windows SmartScreen may warn before it starts. Tool packs are signed separately and verified before they run. The release notes list the known limitations.

## Privacy and security

PowerTrove processes selected content locally and does not upload it. Network requests check the official GitHub release channel for updates and download the app or tool packs. See [privacy](https://powertrove.net/en/privacy) and [security](https://powertrove.net/en/security) for details and for how to report a vulnerability.

## Build from source

On Windows, install the .NET 10 SDK and the WinUI development tools. Use PowerShell 7:

```powershell
dotnet build PowerTrove.slnx -c Release
dotnet test PowerTrove.slnx -c Release --no-build
```

Run the desktop project from Visual Studio or with `scripts/run-desktop.ps1`. Release builds use the `Core` profile and ship no pack; build with `-p:PowerTroveProfile=Full` to compile every pack into the app for development. See [contributing](CONTRIBUTING.md) for the code structure, [action packs](packs/README.md) for how packs are built, and [alpha delivery](docs/release/alpha.md) for the release checks.
