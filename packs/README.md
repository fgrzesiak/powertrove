# Action packs

PowerTrove's actions come in eight packs: Files, PDF, Images, Media (audio and video), Data, Office, Tables (Excel selections) and E-Invoice. Released apps compile in no pack. Each pack is a signed bundle in the official `packs-v1` release channel, installed per user by Setup or Settings, and run in the separate `PowerTrove.PackHost` worker process. The worker receives only typed inputs: a file selection or a bounded table snapshot. It writes into a staging folder, and the app commits outputs with its no-overwrite pipeline. For development, the `Base` (Files and PDF) and `Full` (every pack) build profiles compile packs into the app; see `src/PowerTrove.Desktop/BuiltInActionPacks*.cs`.

Packs reference the abstractions SDK and standalone FileKit tools. A pack's own adapters implement engine interfaces, and its composition assembly connects them to the pack factory. File transformations use the shared per-file or combined-file pipeline for output planning, cancellation and source preservation. A pack's version follows its source fingerprint, so a pack is released again only when it changes.

See [contributing](../CONTRIBUTING.md), [manifest metadata](../docs/references/action-pack-manifest.md) and [alpha acceptance](../docs/release/alpha.md). Stable action and pack IDs keep the `powertrove.*` prefix for compatibility. Only first-party packs signed with the official key are installed; these contracts do not authorize third-party loading.
